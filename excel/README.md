# SupplyPulse Excel Analyst Pack

The workbook is the first layer of the analytics pipeline and demonstrates the business-analysis stage before SQL and Python.

## Included sheets

- README — business objective, workflow and KPI definitions
- Raw_Data — representative daily inventory sample
- Data_Quality — control checks and data-quality metrics
- SKU_Analysis — formula-driven reorder point, stock coverage and risk metrics
- Category_Analysis — inventory and revenue-risk summary
- Monthly_Trend — monthly sales and inventory trend
- Dashboard — executive KPI cards and charts

A companion workbook is supplied with the project deliverables as SupplyPulse_Analysis.xlsx.

The workbook is a 120-SKU × 60-day representative sample. The Python generator produces the full 500-SKU × 365-day portfolio.
